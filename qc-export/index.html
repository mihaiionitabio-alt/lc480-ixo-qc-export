LightCycler 480 — raw values, open formats and quality control

Reads a finished .ixo experiment, hands you the numbers the instrument stored, and writes them in formats that open-source tools read directly. Nothing is uploaded; everything runs in this page.

Load an experiment

Drop one or more .ixo files, or a .zip containing them. Several runs can be loaded at once — the Quality review tab compares them.

Drop .ixo or .zip here
or click to choose files
Or paste Cq values from any instrument

A pasted table can be tidied and downloaded again, but it carries no fluorescence, so the curve-based exports need an .ixo file. Paste or upload a table with a sample column and a Cq column — the header names are matched loosely, so exports from most instruments work as they are. A well column is used if present.

Read from the experiment file

Everything below was taken out of the container itself. Nothing here was typed, assumed or defaulted — each line names the property it came from, so a value you disagree with can be traced back to the bytes it was read from.

What was read

Stored values, exactly as the instrument wrote them

Nothing here is recomputed. Cq is the crossing point the LightCycler stored; concentration is its CalcConc; the call is its own classification. Download the table for your own analysis.

Formats other tools read

Each download states which tool consumes it and what was checked. Where a format has a version that matters, the version that actually works is used rather than the newest or the oldest.

Quality review

    
Inspect the plate, compare samples, review descriptive statistics, follow controls across
      experiments, inspect the stored curves, and audit the instrument record. Calculations are descriptive;
      stored Cq, calls and fluorescence are never replaced.

Plate map

Sample comparison

      
Table-first, side-by-side comparison across every analysis. The review threshold only
        highlights a difference; it does not replace an assay-specific acceptance rule.

      

        
        
        
        
      

      

    


    

      
Statistics and mistake finding

      
Per-analysis descriptive statistics plus targeted review counts for missing curves,
        uncertain calls, large replicate spread and amplified positions omitted from every analysis.

      

        
        
      

      

    


    

      
Control charts

      
Levey-Jennings Cq by experiment. Replicate wells are collapsed to one point per run.
        Limits and Westgard rules are shown only from three or more runs.

      

        
        
        
        
      

      

        Adjust detected control categories
        
The automatic category applies to every dated or capitalised spelling under the
          same root. Change any row without renaming the samples in the source files.

        

        
      

      

    


    

      
Runs, QC and forensic log

      
One row per run, followed by a traceable log of structural findings, provenance and
        instrument-versus-name disagreements.

      

      

    


    

      
Amplification curves

      
Raw fluorescence as stored in the AcquisitionStore, with no smoothing and no baseline
        subtraction. Controls are drawn over ordinary samples so they stay visible.

      

        
        
        
        
        
        
      

      

    


    

      
Instrument records

      
Run metadata, thermal program, detection channels, subsets, analysis objects, standard
        curves and the instrument's own replicate statistics, decoded verbatim from the file.
